ETF Trend Predictor
GitHub Docker Hub

Can technical indicators beat buy-and-hold on European ETFs?

Mostly not. We rebuilt the method of Sagaceta-Mejía et al. (2024) for three European ETFs and the S&P 500: about 250 technical indicators, an MLP and an LSTM, and a strict walk-forward backtest from 2014 to 2026. Three of 16 model runs beat buy-and-hold before costs, and none still does once trading costs reach 6 bps a trade.

Reports

  • Data preparation Prices from Yahoo Finance, the indicator set and how it was checked for look-ahead, the target Γ(t), class balance and cleaning.
  • Statistical analysis Feature variance and redundancy, Random Forest feature importance, stationarity tests and an ARIMA baseline.
  • Modeling and backtests MLP and LSTM walk-forward results per ETF, equity curves, the top-10 feature experiment and trading-cost sensitivity.
  • API reference Documentation for every class and function in the etf_predictor package.

How the experiment works

ETFs
IEUR (broad Europe), FEZ (Euro Stoxx 50) and EUFN (European financials), with IVV (S&P 500) as a benchmark
Data
Daily prices from Yahoo Finance, 2010 to April 2026
Features
About 250 pandas-ta indicators, each tested to make sure it only uses past prices
Models
An MLP that classifies the daily direction and an LSTM that predicts the next day's return
Validation
Expanding-window walk-forward: retrain on all history so far, test on the next six months, repeat
Trading
Long or short every day on the model's signal, compared with buying and holding the same ETF

Run it yourself

One Docker image runs the whole pipeline, from downloading prices to rendering the three reports, in 10 to 15 minutes on a laptop CPU.

docker pull milankalajdzic/etf-predictor:latest
mkdir output
docker run --rm -v "$PWD/output:/output" milankalajdzic/etf-predictor:latest

Based on Sagaceta-Mejía, Sánchez-Gutiérrez and Fresán-Figueroa (2024), “An intelligent approach for predicting stock market movements in emerging markets using optimized technical indicators and neural networks”, Economics 18.
